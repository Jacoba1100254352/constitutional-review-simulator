\section*{Supplementary Appendix Scope}

This appendix preserves technical detail that is too large for the main Journal of Law and Courts manuscript: fixed model weights, full starter-campaign diagnostics, sensitivity-campaign diagnostics, calibration source-observation status, and generated report artifacts. The review replication archive includes Java source code, tests, configuration inputs, aggregate generated reports, provenance manifests, and build commands. Full compressed case-level outputs are generated by the same commands and should be deposited with the final public replication archive or supplied separately if requested during review.

The sensitivity matrix reports the same scenario catalog under high and low assumptions for emergency pressure, appointment polarization, rights-threat rate, public trust, and legislature-court conflict.
