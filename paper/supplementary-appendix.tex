\section*{Supplementary Appendix Scope}

This appendix preserves technical detail that is too large for the main Journal of Law and Courts manuscript: fixed model weights, full main-campaign diagnostics, sensitivity-campaign diagnostics, calibration source-observation status, empirical data-development files, and generated report artifacts. It is organized around the manuscript's evidentiary split. Real-world presets are institutional mappings, synthetic mechanisms are counterfactual design tests, candidate rows are validation inputs only after primary-source verification, and speculative design recommendations should be read only after checking uncertainty, implementation cost, transplant feasibility, political-culture sensitivity, case-selection access, implementation capacity, legislative-response timing, and legislative-response credibility. The main manuscript centers emergency constitutional review; the wider scenario catalog is retained here so emergency-process reforms can be compared against appointment, council, override, weak-form, and front-end review mechanisms under the same generated worlds. The replication archive includes source code, tests, configuration inputs, aggregate generated reports, provenance manifests, and build commands. Full case-level and interval outputs are generated by the same commands and should be deposited with the final public replication archive or supplied separately if requested during review.

\section*{Sensitivity Matrix}
The sensitivity matrix reports the same scenario catalog under high and low assumptions for emergency pressure, appointment polarization, rights-threat rate, public trust, and legislature-court conflict. The purpose is to expose parameter dependence before treating any design comparison as substantively stable. The columns emphasize democratic constitutionalism, veto-relocation risk, transplant feasibility, and political-culture sensitivity because those are the key additions for evaluating review as democratic infrastructure rather than as judicial veto power.
