# Challenge objects and statute dispositions

## Statistical unit

Each case contains one or more `ChallengeObject` records. An object represents
one instrument or act challenged in that case, not each section of an instrument
and not each legal argument. Its ID is unique within the case. The same law
challenged in a later case is a new case-object observation, not a globally
deduplicated statute. A mixed-jurisdiction case can contain separate federal and
state objects; every object identifies one government level.

`statuteNullificationRate` is the pooled number of statute objects with a
`NULLIFIED` disposition divided by statute objects reached on merits. It is
undefined (`NaN`, denominator zero) when no statutes receive a merits disposition.
The denominator includes upheld statutes and weak-form declarations. Regulations
and government conduct are separately typed and excluded. Conduct relief is not
statute nullification. Declined cases and emergency-only orders have
`NOT_REACHED` dispositions and do not enter the denominator. Suspended
nullifications count at decision time. A later legislative override does not
erase the original judicial disposition. Weak-form declarations do not count as
nullifications.

## Model assumptions and interpretation

The existing institutional model decides the case. The new layer allocates that
decision among the case's objects. On a decision granting relief, the most
vulnerable object and any others within 0.20 of its vulnerability receive relief;
the remaining objects are upheld. On a merits decision without relief, all
objects are upheld. This is a conditional allocation model, not independent
voting on each object, a model of partial procedural dismissals, or an empirical
estimate of remedy severability.

The default object count is 1, 2, or 3 with probabilities 0.75, 0.20, and 0.05.
Object types are statute, regulation, and conduct with probabilities 0.50, 0.15,
and 0.35. Vulnerability is uniform on [0,1]. Mixed-level cases allocate each
object's government level with equal probability. These are explicit synthetic
assumptions, not frequencies estimated from the Canadian article or any court.
Imported legislative CSVs remain stress signals; object annotations are synthetic
and do not assert what instruments the exporting simulator actually enacted.

Object generation uses a separate seeded stream and does not consume draws
from the case, court-vote, or reaction streams. The new diagnostic has no
normative score weight. All assumptions are recorded in each campaign manifest.
During regression checks a pre-existing seed defect was found: the world's
record hash included the doctrine enum's process-local identity hash. The same
committed source could therefore generate different worlds in fresh JVMs.
World seeds now use an explicit value fingerprint, versioned in the manifest.
Existing source ranges and institutional mechanisms are unchanged; old
aggregate numbers are not a bit-for-bit reference for this seed migration.
The fresh-process test perturbs identity-hash history and compares full outcome
digests under both doctrine profiles. See `docs/measurement-evidence-audit.md`.

## Auditable outputs

Campaign aggregate CSVs contain `statuteDispositions`, `statuteNullifications`,
and `statuteNullificationRate`. Case CSVs contain the two counts. A companion
`*-objects.csv.gz` contains one row per object, keyed by campaign case, scenario,
run, case, and object ID, plus its type, level, exact vulnerability, disposition,
suspension, and inclusion flags. This makes the numerator and denominator
reconstructible without trusting the aggregate rate or rounding.

Campaign interval files resample whole simulation runs, retaining related
objects in the same case. Bootstrap replicates with no statute dispositions
cannot estimate this rate and are omitted for this diagnostic. Raw object files
are included in provenance manifests and can be regenerated by the same campaign
commands. Like raw case files, they are excluded from the compact anonymous
review ZIP and belong in the full public replication deposit.

The statute calibration CSV, calibration-interval CSV, and Markdown diagnostic
also resample run blocks. Fewer than two runs or no statute dispositions yields
an undefined band. Existing calibration measures retain their documented
denominator-based intervals. Neither interval type represents model uncertainty.

## Canadian measurement mismatch

The checked-in source audit of Morton, Russell, and Withey (1992), Table 7,
records 19 nullifications among 50 federal and provincial statute dispositions.
The article's 100 decisions are a different unit. Table 6's 49 statute-challenge
objects and 103 total challenge objects are another tabulation and must not
silently replace Table 7's denominator. Source URL:
https://digitalcommons.osgoode.yorku.ca/ohlj/vol30/iss1/1/

A structurally matching simulator output permits a narrow source-range
comparison. It does not show that the source's historical docket, selection,
object mix, or decision process has been reproduced. Promotion and manuscript
claims must preserve this boundary; matching a broad source interval is not
independent validation of the conditional allocation assumptions.
